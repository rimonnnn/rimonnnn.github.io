Grid World AI Game

An interactive AI game that demonstrates Simple Reflex Agent and Q-Learning Agent.

Game Rules

🤖

Agent starts from (0, 0).

💎

Goal is located at (3, 3).

🔥

Fire cells are losing cells.

Goal Reward: +20

Fire Penalty: -20

Move Penalty: -1

Choose an agent to start

About This Game

This project simulates an AI agent moving inside a 4x4 grid. The Simple Reflex Agent follows rules, while the Learning Agent uses Q-Learning to improve its decisions based on rewards and penalties.
