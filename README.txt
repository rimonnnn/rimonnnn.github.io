Portfolio typography update

Contents:
- index.html: requests IBM Plex Sans Arabic, Inter, and Space Grotesk from Google Fonts.
- css/: complete CSS folder with font and size refinements.

Installation:
1. Back up your current index.html and css folder.
2. Replace index.html with the included file.
3. Replace the current css folder with the included css folder.
4. Keep your existing js, assets, certificates, and other files unchanged.

Design changes:
- Replaces Cairo with IBM Plex Sans Arabic for the Arabic locale.
- Reduces oversized hero, section, project-card, and modal headings.
- Improves paragraph line height and Arabic heading spacing.
- Keeps English typography in Inter and Space Grotesk.
- No package or build step is required.
