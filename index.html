Special AI Project

Grid World Q-Learning Game

An interactive Python/Tkinter game that demonstrates Q-Learning concepts where an agent learns to reach a goal while avoiding fire cells using rewards, penalties, and a Q-table.

Problem / Purpose

Show practical understanding of reinforcement learning by creating a visual grid environment where an agent makes decisions and improves through Q-values.

My Role

Built the game logic, grid movement rules, reward/penalty system, Q-table storage, and interactive Tkinter interface.

Key Features
  • Agent starts from a fixed position
  • Goal cell with positive reward
  • Fire cells with penalties
  • Q-table based learning behavior
  • JSON file used to save learned Q-values
Technical Highlights

Reinforcement learning basics, Q-Learning update logic, reward design, Tkinter UI, and JSON persistence for Q-table data.
